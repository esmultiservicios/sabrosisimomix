# 🏠 Castro’s Ready — Corporate Website & Custom CMS

> **More Than Repairs and Maintenance. We Care About Your Home.**

The project combines a responsive public landing page with a secure administration panel designed so non-technical users can manage content, multimedia, services, website appearance, requests, SEO, security and operational settings without editing code.

## Administrator ownership reset

A protected ownership reset workflow is available for formal website handoff.

It requires:

- Current password
- Explicit `RESET ADMIN` confirmation

This removes administrator accounts and signs the current owner out, but does **not** delete website content, services, gallery images, settings, email configurations or estimate requests.

# 🧙 Installation Wizard

A new installation is performed through:

```text
/install/
```

The installer uses a guided 3-step workflow:

### Step 1 of 3 — Database
Enter the MySQL connection information.

### Step 2 of 3 — CMS Ready
The installer imports the complete database schema and creates the local application configuration.

### Step 3 of 3 — Administrator
Create the first Owner account.

The installer generates installation-specific files such as the database configuration and encryption key.

---

# 🗄️ Database Files

Two database files are intentionally provided.

## `database.sql`

Use this only for a **new installation**.

The installation wizard imports it automatically.

## `database-update.sql`

Use this for an **existing compatible Castro’s Ready installation** that needs the latest schema updates.

The cumulative update is designed to avoid unnecessary duplicates using safe migration patterns such as:

```sql
CREATE TABLE IF NOT EXISTS
INSERT IGNORE
ON DUPLICATE KEY UPDATE
WHERE NOT EXISTS
```

> ⚠️ Never import `database.sql` over an existing production database.

Always create a backup before applying database updates.

# ✅ Recommended Administrative Workflow

Before an important website update:

1. Create a backup.
2. Make the content change.
3. Preview the result.
4. Verify desktop, tablet and mobile.
5. Publish.
6. Review the public site.
7. Check Website Health if relevant.

For multimedia:

1. Upload or select the asset.
2. Preview it.
3. Confirm title / order / visibility.
4. Save.
5. Verify the public presentation.
